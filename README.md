# FoodHub

Food delivery for VIT-AP University students. *For the campus cravings.*

Built with Next.js, TypeScript, Tailwind CSS and Supabase.

## Run it

```bash
npm install
cp .env.local.example .env.local   # then fill in your own values
npm run dev
```

## Useful commands

- `npm run build`: production build
- `npm run lint`: ESLint
- `npm run audit:contrast`: checks the theme's colour contrast
- `node scripts/build-brand-assets.mjs`: rebuilds icons from the logo

Database migrations are in `supabase/migrations`.
